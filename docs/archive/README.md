# Documentation Archive

This folder holds documentation that is **superseded or purely historical** — kept for
reference and git history, but not part of the active documentation set. Nothing here
should be treated as current.

For current, authoritative documentation, see:
- **`AI Handover/`** at the repo root — the canonical package for onboarding onto the
  Real Estate (DPRE) branch (architecture, schema, use cases, current state, credentials).
- **`C8.eServices.Mvc/Use cases/`** — living reference docs that are still accurate
  (view/UI standards, workflow status KB, audit trail architecture, the EHC branch's
  `Unified_Use_Cases.md`, and the Real Estate `STANDARDS.md` / `Usage_Guide_Real_Estate.md`).

## `ehc-dev-history/`
One-off "fix", "status", "summary", and "complete" notes written during earlier EHC
(Housing) branch development, dated January–March 2026. Each documents a specific bug
fix or feature landing that has long since been merged into the codebase; none were
updated after March 27, 2026. Kept for historical traceability only.

- `pdftemplates/` — implementation-status notes for the Revised Lease Agreement PDF
  field-mapping work (March 2026), now superseded by the current PDF template files.
- `scripts/` — one-off setup/fix notes for the `Scripts/` folder (the living reference,
  `Scripts/TEST_CASES_README.md`, was left in place).
