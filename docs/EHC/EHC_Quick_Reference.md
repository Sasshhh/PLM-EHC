# How to read this card

Each table lists the work a role does, the side-navigation path, and the button to click on the item in the list. The full steps are in the *EHC SOPs* (SOP number in the last column). Every Submit asks for confirmation: click **Yes, I am sure!**.

# Applicant / Tenant

| I want to… | Side navigation | Button | SOP |
|---|---|---|---|
| Apply for a unit | PLM Applications › Capture | Next, Submit | A2 |
| Upload proof of the application fee or deposit | PLM Applications › Inbox | Upload Proof Of Payment | A3, A5 |
| Accept a unit offer | PLM Applications › Inbox | View › Accept | A4 |
| Confirm I still need a unit | PLM Applications › Inbox | Unit Still Required? | A6 |
| Do the training and exam | My Training › Pre-Tenancy Training | Start Training, Submit Examination | A7 |
| Pick an inspection time | PLM Applications › Inbox | Unit Inspection Schedule | A8 |
| Sign my lease | PLM Applications › Inbox | Agreement Validation | A9 |
| Lodge a complaint | Complaints › Lodge New Complaint | Submit Complaint | A10 |
| Log a service request | Service Requests › Create Service Request | Submit Request | A11 |
| Register a dispute | Disputes › Register Lease Dispute | Register Dispute | A12 |
| Accept a renewal | Renewals › Lease Renewals | Renewal Available, Upload Document(s) | A13 |
| Give notice | Notice › Serve Notice | Serve Notice | A14 |
| See my lease and occupants | Tenants › My Leases / Manage Tenants | | A15 |

# Lease statuses you will see

| Status | Waiting for |
|---|---|
| In Awaiting Application Fee Upload | Applicant to upload fee proof |
| In Awaiting Application Fee Validation | Revenue Officer |
| Awaiting Risk Assessment | CSO |
| Available Unit Matched | Applicant to accept the offer |
| Awaiting Deposit Payment | Applicant to pay and upload |
| Payment Validated and Approved | CSO to invite to training |
| Awaiting Online Training | Applicant |
| Awaiting Inspection / In Awaiting Unit Inspection Schedule | Housing Supervisor / applicant to pick a slot |
| In Awaiting Maintenance Job Sheet | Maintenance Manager |
| Awaiting Lease Agreement / In Awaiting Lease Agreement | CSO |
| In Awaiting Lease Agreement Approval | Revenue Manager, then CEO |
| Active Lease | Nothing: the lease is running |
| In Awaiting Application Lease Renewal Review | CSO to recommend |
| Awaiting Renewal Review Outcome | Revenue Manager |
| Awaiting Renewal Outcome | CEO |
| In Awaiting Tenant Renewal Acceptance | Tenant |
| In Awaiting Renewal Document(s) Upload | Tenant |
| Awaiting Lease Renewal Agreement Conclusion | CSO to capture renewal details |
| Awaiting Renewal Agreement Generation | CSO |
| Awaiting Renewal Tenant / RM / CEO Signature | Tenant, Revenue Manager, CEO |
| Awaiting CSO Termination Review | CSO |
| Awaiting Termination Appraisal | Revenue Officer |
| Awaiting Eviction CEO Authorization | CEO |
| Awaiting Eviction Service / Eviction Notice Served | CSO |
| In Awaiting Exit Inspection | CSO to schedule, Housing Supervisor to inspect |
| In Awaiting Vacating Confirmation | CSO |
| Applicant Vacated The Unit | CSO to start the refund |
| Awaiting Refund Response | Revenue Manager |
| Awaiting Refund Authorisation | CEO |
| Lease Terminated | Nothing: closed |
