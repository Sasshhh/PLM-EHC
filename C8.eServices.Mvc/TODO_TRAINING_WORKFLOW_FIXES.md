## ?? **DATABASE VERIFICATION QUERIES**

### **Check Status Flow:**
```sql
SELECT 
    pla.ApplicationReferenceNumber,
    pla.Id AS AppId,
    s.Name AS CurrentStatus,
    s.[Key] AS StatusKey,
    tt.IsTrainingCompleted,
    tt.IsExamPassed,
    tt.ExamAttempts,
    CASE 
        WHEN s.[Key] = 's_awaiting_online_training' THEN '? Step 1: Invited'
        WHEN s.[Key] = 's_training_in_progress' THEN '? Step 2: In Progress'
        WHEN s.[Key] = 's_training_completed' THEN '? Step 3: Completed'
        WHEN s.[Key] = 's_examination_failed' THEN '?? Step 4a: Failed (Retake)'
        WHEN s.[Key] = 's_examination_passed' THEN '? WRONG! Should be inspection slots'
        WHEN s.[Key] = 's_awaiting_inspection_schedule_slots' THEN '? Step 4b: Ready for Inspection'
        ELSE '?? Unknown Status'
    END AS WorkflowStep
FROM PropertyLeaseApplications pla
INNER JOIN Status s ON pla.StatusId = s.Id
LEFT JOIN TenantTrainings tt ON pla.Id = tt.PropertyLeaseApplicationId
WHERE pla.ApplicationReferenceNumber = 'EHC2023101800005';
```

### **Check Round Robin Assignments:**
```sql
SELECT 
    rrq.Id AS QueueId,
    pla.ApplicationReferenceNumber,
    rt.Name AS ResponsibilityType,
    rt.[Key] AS ResponsibilityKey,
    rrq.IsDone,
    rrq.CurrentTaskDateTime AS AssignedDate,
    rrq.EndTaskDateTime AS CompletedDate,
    u.UserName AS AssignedTo,
    CASE 
        WHEN rt.[Key] = 'rt_invite_to_client_training' THEN '? Should exist after ClientTraining()'
        WHEN rt.[Key] = 'rt_schedule_inspection_slots' THEN '? Should exist AFTER exam pass ONLY'
        ELSE rt.[Key]
    END AS ExpectedBehavior
FROM RoundRobinQueues rrq
INNER JOIN PropertyLeaseApplications pla ON rrq.PropertyLeaseApplicationId = pla.Id
INNER JOIN ResponsibilityTypes rt ON rrq.ResponsibilityTypeId = rt.Id
LEFT JOIN SystemUsers u ON rrq.AssignedUserId = u.Id
WHERE pla.ApplicationReferenceNumber = 'EHC2023101800005'
ORDER BY rrq.CreatedDateTime DESC;
```
